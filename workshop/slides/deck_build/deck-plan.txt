Communication job
By the end, a highly technical healthcare/AI audience should understand how to build a query-driven, evidence-grounded medical-device ALM agent because the architecture separates probabilistic reasoning from typed data tools, deterministic policy, sandboxed computation, and human governance.

Hospital fleet scale -> fragmented data -> MAUDE semantics and limits -> controlled synthetic data -> query-driven architecture -> code/tool boundaries -> OpenShell execution -> observed evaluation evidence -> live demo and reuse.
